# "docs" Folder

### What is this? 
The docs folder is where specifications are saved; specifications provide details about the request parameters and functionality of the QA Mother Infant Linkage (MIL) package.

While Sentinel does not directly support use of our tools, we welcome feedback, comments, and suggestions pertaining to our documentation or tools. Email us [<b>here.</b>](mailto:info@sentinelsystem.org?subject=Git)
